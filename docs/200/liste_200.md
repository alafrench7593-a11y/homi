## Exigences transverses (résumé)
- Les 200 dans le catalogue, jamais tous sur l'accueil ; accueil 6–10 outils : Pour toi aujourd'hui · Tes favoris · Continuer · Ton enfant · Explorer.
- Moteur de recommandation déterministe (profil, âge, étapes de vie, priorités, favoris, récents, événements), recalcul automatique (grossesse→naissance→bébé→enfant, diversification, école, nounou) ; épinglés toujours visibles ; jamais de suppression de données.
- Onboarding 6 étapes : profil (multi), situation familiale, enfants/grossesse, alimentation du nourrisson, priorités (multi), tableau de bord personnalisé.
- Registre : id, name, description, category, route, icon, lifeStages, ageRange, requiredPermissions, requiredData, recommendationRules, isFavorite, isAvailable, aiMode.
- Mutualiser calendriers, chronomètres, rappels, graphiques, formulaires, historiques, notifications.
- IA seulement si utile (aiMode) ; classique toujours fonctionnel sans IA.
- Profils de test A–G (enceinte ; bébé 2 mois allaité ; papa bébé 8 mois ; enfant 6 ans ; nounou ; multi-enfants ; sans infos).
- Livrables : HOMI_200_TOOLS_AUDIT.md, HOMI_200_TOOLS_IMPLEMENTATION_REPORT.md, matrice de personnalisation.
