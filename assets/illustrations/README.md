# Illustrations 3D HOMI

Illustrations originales générées le 16/11/2026 (ElevenLabs Flows, modèle gpt-image-2.5-sunburst), puis détourées
(birefnet-v2) : fond transparent, carré 768 × 768, WebP. Mêmes personnages et même lumière (corail / rose / lilas)
d'une image à l'autre. Inspirées d'une direction artistique de référence, sans en reprendre personnages ni logo.

| Fichier | Usage prévu |
|---|---|
| `famille.webp` | Écran d'entrée (welcome), ouverture de l'onboarding |
| `projet-bebe.webp` | Onboarding : « On essaie d'avoir un enfant » |
| `grossesse.webp` | Onboarding grossesse, écran Grossesse |
| `bebe.webp` | Onboarding bébé, espace Bébé |
| `enfants.webp` | Onboarding enfants |
| `cycle.webp` | Onboarding cycle, espace Cycle |
| `foyer-maison.webp` | Onboarding foyer, espace Famille, accueil |
| `foyer-pret.webp` | Révélation « votre foyer est prêt » |

Les fichiers sources (16:9, fond ivoire rosé) restent dans l'espace ElevenLabs du compte.
