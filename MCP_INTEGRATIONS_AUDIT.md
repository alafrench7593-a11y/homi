## 4. Recommandation

1. **Maintenant, sans rien connecter** : continuer avec Playwright Python + Jest ; appliquer les règles R1–R21 de `GITHUB_SKILLS_AUDIT.md`.
2. **Dès qu'un dépôt distant existe** : GitHub MCP en **lecture seule** (`repos`, `actions`, `pull_requests`).
3. **Pour les migrations** : Supabase MCP **local** (CLI), advisors de sécurité ; jamais la production.
4. **Quand un simulateur est disponible** : Maestro (libre) pour 5 à 10 parcours critiques (connexion, saisie d'une tétée, relais de nuit, bilan post-partum, abonnement).
5. **Non recommandés** dans le cadre actuel : Radon (licence payante), EAS Simulator (payant), Figma MCP (pas de maquettes), Expo MCP distant (intérêt surtout pour EAS et magasins, à revoir au moment de la publication).
